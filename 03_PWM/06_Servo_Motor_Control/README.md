# 06 Servo Motor Control

## Objective
Control a hobby servo motor using a 50 Hz PWM signal.

## Required Components
- Pico W, hobby servo motor, suitable external 5V supply

## Hardware Connections
GP17 -> servo signal; servo VCC -> external regulated supply; servo GND -> supply GND and Pico GND.

## Program
See `main.py`.

## Expected Result
Run the program on Raspberry Pi Pico W and observe the output or hardware response described by the experiment.

## Learning Outcomes
- Understand the relevant MicroPython peripheral.
- Learn the hardware connections.
- Observe and modify the program behaviour.
