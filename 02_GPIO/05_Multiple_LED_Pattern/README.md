# 05 Multiple LED Pattern

## Objective
Control multiple GPIO outputs to generate a running LED pattern.

## Required Components
- Pico W, 3 LEDs, 3 resistors

## Hardware Connections
Connect GP2, GP3 and GP4 to separate LED anodes through resistors. Connect LED cathodes to GND.

## Program
See `main.py`.

## Expected Result
Run the program on Raspberry Pi Pico W and observe the output or hardware response described by the experiment.

## Learning Outcomes
- Understand the relevant MicroPython peripheral.
- Learn the hardware connections.
- Observe and modify the program behaviour.
