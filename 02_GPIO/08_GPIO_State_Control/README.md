# 08 GPIO State Control

## Objective
Use a digital input to control an output and display its state.

## Required Components
- Pico W, push button, LED, resistor

## Hardware Connections
GP14 to 3.3V through push button; GP2 to LED through resistor.

## Program
See `main.py`.

## Expected Result
Run the program on Raspberry Pi Pico W and observe the output or hardware response described by the experiment.

## Learning Outcomes
- Understand the relevant MicroPython peripheral.
- Learn the hardware connections.
- Observe and modify the program behaviour.
