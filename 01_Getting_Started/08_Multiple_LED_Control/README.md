# 08 Multiple LED Control

## Objective
Control three LEDs sequentially.

## Requirements
- Raspberry Pi Pico W
- MicroPython firmware
- USB cable

## Hardware Connections
- GP14, GP15 and GP16 -> individual resistors and LEDs -> GND.

## Program
Refer to `main.py`.

## Learning Outcome
Understand the basic MicroPython programming concepts and Raspberry Pi Pico W hardware interfacing.
