# 03 External LED Blink

## Objective
Control an external LED using GP15.

## Requirements
- Raspberry Pi Pico W
- MicroPython firmware
- USB cable

## Hardware Connections
- GP15 -> 220-330 ohm resistor -> LED anode; LED cathode -> GND.

## Program
Refer to `main.py`.

## Learning Outcome
Understand the basic MicroPython programming concepts and Raspberry Pi Pico W hardware interfacing.
