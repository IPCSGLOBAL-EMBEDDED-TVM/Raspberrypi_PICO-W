# 05 Button Controlled LED

## Objective
Control an LED using a push button.

## Requirements
- Raspberry Pi Pico W
- MicroPython firmware
- USB cable

## Hardware Connections
- GP14 -> push button -> 3.3V. Internal pull-down enabled.
- GP15 -> resistor -> LED anode; LED cathode -> GND.

## Program
Refer to `main.py`.

## Learning Outcome
Understand the basic MicroPython programming concepts and Raspberry Pi Pico W hardware interfacing.
