
# Experiment 01 - Hello World

## Objective
To execute the first MicroPython program on Raspberry Pi Pico W and display messages through the serial terminal.

## Requirements
- Raspberry Pi Pico W
- USB cable
- MicroPython firmware
- VS Code or rshell

## Program
Refer to `main.py`.

## Expected Output
```text
Hello World!
Welcome to Raspberry Pi Pico W
MicroPython is running successfully
```

## Learning Outcome
- Understand MicroPython execution.
- Use the print() function.
- View program output through the serial terminal.
